# Bug修复总结 - 2026-01-02

## 修复的Bug

### Bug 1: Action维度不匹配 ✅ FIXED
**问题描述：**
- 配置文件中设置 `action.dim: 14`
- F1-VLA模型实际输出7维动作
- 导致训练过程中出现1564次警告: "Action dim mismatch: got 14, expected 7, truncating..."

**根本原因：**
- Mock环境使用配置中的action_dim创建action_space
- Explorer模型输出与环境期望维度不一致

**修复方案：**
```yaml
# f1_vla/config/explorer_train_config.yaml
action:
  dim: 7  # 修正为F1-VLA实际输出维度
```

**验证结果：**
- ✅ 日志显示: `Environment action_dim=7`
- ✅ 无任何action维度警告
- ✅ 训练顺利进行100k steps

### Bug 2: Checkpoint保存崩溃 (第一次) ✅ FIXED
**问题描述：**
```python
ValueError: Unknown format code 'd' for object of type 'str'
```

**根本原因：**
```python
# explorer_trainer.py (旧代码)
def save_checkpoint(self, episode: int):
    checkpoint_dir = self.output_dir / f"checkpoint_{episode:06d}"  # episode是int
    
# train_explorer.py 调用时传入了str
self.phase1_trainer.save_checkpoint(str(checkpoint_path))  # 传入str!
```

**修复方案：**
```python
# 修改方法签名接受完整路径
def save_checkpoint(self, checkpoint_path: str):
    checkpoint_dir = os.path.dirname(checkpoint_path)
    os.makedirs(checkpoint_dir, exist_ok=True)
    # ...
```

**验证结果：**
- ✅ 训练完成100k steps
- ✅ 保存了 `final.pth` (3.8MB)
- ✅ 保存了 `final_explorer.pt` (1.6GB)

### Bug 3: Checkpoint保存崩溃 (第二次) ✅ FIXED
**问题描述：**
```python
TypeError: unsupported operand type(s) for /: 'str' and 'str'
```

**根本原因：**
```python
# explorer_trainer.py (部分修复后的代码)
checkpoint_dir = os.path.dirname(checkpoint_path)  # 返回str
torch.save(self.log_std.data, checkpoint_dir / 'log_std.pt')  # 试图用str做Path操作!
```

**修复方案：**
```python
# 所有路径操作使用os.path.join
log_std_path = os.path.join(checkpoint_dir, 'log_std.pt')
torch.save(self.log_std.data, log_std_path)

state_path = os.path.join(checkpoint_dir, 'training_state.json')
with open(state_path, 'w') as f:
    json.dump(state, f, indent=2)
```

**验证结果：**
- ✅ 路径操作测试通过
- ✅ 可以正常保存所有checkpoint文件
- ✅ Checkpoint可以成功加载

## 代码改进

### 1. Action维度处理优化
```python
# 支持padding和truncate两种情况
if actions.shape[-1] != action_mean.shape[-1]:
    if actions.shape[-1] > action_mean.shape[-1]:
        # Truncate
        actions = actions[..., :action_mean.shape[-1]]
    else:
        # Pad with zeros
        pad_size = action_mean.shape[-1] - actions.shape[-1]
        actions = torch.cat([actions, torch.zeros(..., pad_size, ...)], dim=-1)
```

### 2. Checkpoint保存格式统一
- 主checkpoint包含: optimizer, value_head, scheduler
- Explorer actor单独保存 (便于加载)
- 训练状态保存为JSON (便于查看)

### 3. 路径操作统一
- 统一使用 `os.path.join()` 而不是 Path `/` 操作符
- 避免str和Path混用导致的类型错误
